# Terminal design

Use the user's terminal theme and font. Use its native ANSI palette for semantic hierarchy: bold cyan headings and prompts, green ready savings/success, amber review blockers and recovery caveats, bold red permanent-checkout-removal warnings. Never rely on color alone or force a light/dark background. Auto mode colors terminals only, independently for stdout/stderr; honor NO_COLOR and TERM=dumb. Explicit --color always/never overrides auto; JSON never gets ANSI. Reset each styled segment before input and wrap/sanitize text before styling. Use short headings, aligned size columns, plain-language status and blank-line separation. Project labels identify the workspace and repository; full paths and machine IDs belong in explicit details. Escape control characters in filesystem names and advisory text. Default reports summarize totals and show the largest opportunities, while detail mode retains exact evidence. Approval prompts describe effects in short numbered steps and distinguish cache removal from deleting the checkout.
